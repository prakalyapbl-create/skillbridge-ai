SkillBridge AI

"From Skill Gaps to Career Opportunities"

Empowering college students with AI resume analysis, skill gap mapping, multilingual learning in Tamil, English & Hindi, practical projects, and verified opportunity matching.

🌐 Live App: https://prakalyapbl-create.github.io/skillbridge-ai/ Target: College Students & Fresh Graduates

01. The Problem Statement

College students face severe confusion when transitioning from academics to technical careers:

❌ Skill Ambiguity

78%+ of students do not know what technical skills they are missing for specific roles like Software Developer Intern.

❌ Resource Disconnection

Students get trapped in unguided YouTube tutorials without structured weekly roadmaps or trusted source verification.

❌ Regional Language Barrier

Students comfortable in Tamil or Hindi lack structured guidance explaining complex tech concepts in their native language.

❌ Keyword Stuffing & Fake Resumes

Students resort to fake online resume generators, leading to immediate rejection during technical interviews.

02. The SkillBridge AI Solution

SkillBridge AI creates a continuous 7-step career development cycle:

1. Profile & Resume AI skill extraction without qualification fabrication.
2. Skill Gap Mapping GREEN / YELLOW / RED status categorizations.
3. Multilingual Learn Trusted resources in Tamil, English, and Hindi.
4. Practical Projects Portfolio builds with resume bullet guidance.
5. Dual Resume Studio Mode A Builder + Mode B Resume Tutor AI.
6. Opportunity Match Devpost, Unstop & Official Company listings.
7. SkillBreak Games 3-Minute educational code puzzles & quizzes.

03. Full-Stack Architecture

Frontend & State Layer
  • ⚡ Next.js 14 App Router: React full-stack framework with Static Export capability.
  • 🎨 Tailwind CSS & Lucide: Modern student-friendly UI components.
  • 📊 Recharts & Canvas Confetti: Visual career timelines & reward animations.
Backend & Deployment
  • 🐍 Python FastAPI Microservice: Standalone API server in `backend/main.py`.
  • 🤖 AI Reasoning Engine: Contextual support for Tamil (`ta`), Hindi (`hi`), English (`en`).
  • 🚀 GitHub Actions CI/CD: Automated static build & deployment to GitHub Pages.
